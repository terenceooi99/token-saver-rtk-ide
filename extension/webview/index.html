Turn off RTK-RG & Token Saver?

Turning RTK-RG / Token Saver off pauses command output filtering and removes active optimization rule blocks from your IDE configuration files.

1
Shell command compression paused Agents will run unfiltered shell commands instead of rtk-prefixed commands.
2
Agent directives & skills hidden Rule blocks in .cursorrules, CLAUDE.md, copilot-instructions.md, and AGENTS.md are removed and upstream skills are hidden from the slash-command list.
3
Unfiltered context usage Command output and diffs will use full prompt context until re-enabled.
You can re-enable RTK-RG and Token Saver at any time from the header toggle or status bar.
