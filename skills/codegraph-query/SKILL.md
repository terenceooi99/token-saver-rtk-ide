# CodeGraphContext Query Engine (/codegraph-query)

Queries the pre-indexed semantic AST property graph generated by CodeGraphContext (Upstream: `CodeGraphContext/CodeGraphContext`, CLI: `cgc`).

## Mandatory Semantic Graph First Policy:
AI coding assistants MUST query the CodeGraphContext semantic graph FIRST before attempting to read raw source code files into context.

### Execution Commands:
- Query symbol or function:
  `cgc query "MATCH (n:Function {name: '<function_name>'}) RETURN n"`
- Find all callers of a function:
  `cgc query "MATCH (caller)-[:CALLS]->(target {name: '<function_name>'}) RETURN caller.name, caller.file"`
- Find outgoing calls:
  `cgc query "MATCH (source {name: '<function_name>'})-[:CALLS]->(callee) RETURN callee.name, callee.file"`
- Search symbols across codebase:
  `cgc find "<symbol_pattern>"`
- Inspect module dependencies:
  `cgc query "MATCH (m:Module)-[:IMPORTS]->(dep) RETURN m.name, dep.name"`
